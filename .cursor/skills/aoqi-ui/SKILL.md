# 奥奇界面

做本项目的界面时按这套执行。参考图是王者万象棋的大厅、活动页和设置页。

## 原创边界

王者万象棋只作为设计研究样本，不作为可复制模板。只学习它的构成逻辑、材料层级、透视景深、动效节奏和信息密度控制。不能照抄具体图标、按钮造型、页面构图、文案命名、角色图、皮肤、贴图、音效和动效序列。

奥奇自己的方向是「冷色神迹工艺」：以奥奇精灵、星神、源核、灵纹、图鉴和养成系统为内容核心；视觉上更偏低饱和蓝银、液态玻璃、液态金属、长虹玻璃和连续圆角。每次做页面前先回答：这个设计为什么属于奥奇，而不是任何一款自走棋或卡牌游戏。

## 层次

三层，从后到前：

1. 场景。有透视，焦点清楚，靠近镜头的装饰和画面边缘虚化。景深只打在场景上。
2. 玻璃。导航、任务板、设置行所在的层。能看见底下场景的颜色透出来。
3. 控件。按钮、开关、分段选择比玻璃更厚，文字不虚。

一个画面只有一个主行动。大厅是右下角的大字「开始游戏」。设置页是右下角的「恢复默认」。其余用图标加两个字。

## 从设置页沿用的控件

- 左侧是竖排导航。选中项用一枚亮点，文字更亮，不要再做一块实心选中底。
- 模式预览横排。选中的卡片有一圈亮边，未选中的没有描边。卡片本身是连续圆角。
- 分段选择：几个词横排，选中项是一枚深色胶囊。
- 下拉是深色胶囊，右侧一个箭头。
- 开关是胶囊轨道加圆形旋钮。
- 状态用一枚色点加一个词，例如绿色的「流畅」。
- 主按钮是宽胶囊，顶上有高光。

## 液态玻璃

玻璃是透镜。

- 底下必须还是有透视的场景。模糊后透出场景的颜色，左边偏冷、角色那边偏暖，面板自己不铺一块中性灰。
- 上沿一条亮边，下沿一条暗边。光从左上进来。圆角处亮边跟着弯。
- 主按钮用饱和色和顶面高光。次按钮只用亮边。按钮浮在玻璃前面。
- 能点的玻璃才跟指针有反应。大面积说明板保持安静。

网页实现时，场景层用真实的景深（前景和边缘模糊，主体清楚）。玻璃层用背景采样、模糊、半透明和上下两条边。不要只用 `backdrop-filter: blur()` 加一块灰。

液态玻璃分三档，不能混用：

- 静态玻璃：大面板、设置项、信息栏。`backdrop-filter` + 边光 + 长虹细纹 + 超椭圆裁切。
- 焦点透镜：选中卡片、关键浮层。用 SVG `feDisplacementMap` 做真实背景位移，边缘轻微鼓起。高级感来自形状驱动的折射，不是更大的 blur。
- 神迹晶体：源核、觉醒冲击瞬间。rim、bloom、折射，是页面唯一的视觉主角。

折射、色散、菲涅尔、眩光各自独立可控（参考 `liquid-glass-studio` 的分步渲染：refThickness 20 / refFactor 1.4 / refDispersion 7 / glareFactor 90 / blurRadius 1–200），不要压进一层。

## 苹果 R 角

网上说的三阶贝塞尔，就是三次曲线，也就是 cubic Bezier。苹果的连续圆角不是 `border-radius` 那种四分之一圆弧。圆弧在和直线相接的地方曲率会跳。连续圆角在直线一端曲率是 0，再平滑收到角上。

每个角由两段三阶贝塞尔平滑段夹一小段圆弧组成。平滑度用 Figma 的 corner smoothing。本项目取 60%，接近 iOS 连续圆角，又不会把角拉得过长。半径按控件大小取，按钮大约 22，卡片大约 16 到 20，导航点大约是高度的一半。同一组控件只用一个半径。

支持 `corner-shape: squircle` 的浏览器直接用它。不支持时用 SVG `path` 的 `C` 命令画上面的三次曲线，不要退回普通 `border-radius` 还把它叫做 R 角。

直角只留给真正贴边的分割，例如表格里的细线。按钮、卡片、输入、开关、预览图都用连续圆角。

## 材料分配

这九个词不叠在同一层上。静止画面保持冷、哑、清楚。高饱和和色散只出现在按下、切换、领奖的那一两帧。

| 词 | 用在哪 | 不用在哪 |
|---|---|---|
| 低饱和冷色主视觉 | 整个静止画面。蓝灰、银、薄荷影，饱和度压低 | 主按钮和冲击帧 |
| 哑光反射 | 次级表面：未选中卡片、开关轨道、导航 | 主按钮 |
| 风格化硬表面 | 面板缝、分段选择、预览卡的倒角和内槽，角仍是连续圆角 | 角色和字 |
| 高斯模糊 | 场景景深，以及玻璃背后的背景采样 | 文字和按钮 |
| 长虹玻璃 | 侧栏或卡片一侧的竖向细棱，透出背后颜色 | 正文底下 |
| 液态玻璃 | 任务板、设置层。透镜，透出场景的冷暖 | 代替按钮 |
| 液态金属 | 唯一的主按钮，和一处主角装饰。高光是拉长的镜面 | 大段文字底下 |
| Y2K | 只给那一处金属装饰：铬面、透亮塑料、一小块贴纸高光 | 整页贴图和复古拼贴 |
| 镜头畸变与色散 | 画面最外缘极轻的色边；冲击帧上 1 像素的红青分离 | 正文 |
| 高饱和动效冲击帧 | 按下、页切换、领取成功的 100 到 160 毫秒 | 静止画面 |

静止时的主色是低饱和冷色。主按钮是这一页里唯一的液态金属。冲击帧把饱和度拉高，结束立刻回到冷色。用户要求减少动效时，冲击帧改成颜色直接到位，不做色散和位移。

## 材质阶梯

让材质表达稀有度和品级，这是奥奇区别于同类产品的关键。

- 稀有度：初代哑光 → 幻兽轻玻璃 → 超能长虹玻璃边 → 传说液态金属细边 + Y2K 铬徽章。
- 皮肤品级：良品哑光 → 精品亮线 → 臻品玻璃 → 绝品长虹 → 性转虹彩 → 圣品液态金属边 → 神话 Y2K 铬 + 全息 + 晶体。
- 未探明用磨砂玻璃：轮廓藏在模糊里，解锁时磨砂化开、饱和度冲击、色散分离，再回到冷色实卡。
- 列表多张高稀有度并排时，只有聚焦/选中的那张徽章才转成铬，其余保持扁平刻槽，保住克制。

## 落地组件

网页端复用 `prototype/aoqi-material.css`（token + 材质类）和 `prototype/aoqi-material.js`（超椭圆 `superellipse`、透镜 `lens`、冲击 `impact`、磨砂 `frost`）。材质类：`aq-glass` / `aq-fluted` / `aq-crystal` / `aq-matte` / `aq-hard` / `aq-metal` / `aq-y2k` / `aq-frosted` / `aq-impact`。完整参数与映射见 `docs/04-材质系统.md`。
