# 数据模型

一只精灵一行。职业和皮肤都不止一个，所以各自另开一张表，用种族 ID 连回精灵。

养成六块（等级、装备、源核、星神、灵纹、宠物）继续留空。图鉴里和它们相邻、但已经能看见的，单独占字段，不提前并进养成。

## 精灵

一行一个图鉴条目。样本：神迹悖理·圣祭圣龙。

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| name | 卡片、档案 | 全名，含间隔号 |
| rarity | 列表左栏、详情标题 | 传说、超能、幻兽、初代。未探明是收集状态，不是第五种稀有度 |
| collected | 未探明 / 进度 | 已点亮或未点亮 |
| element | 卡片底部图标 | 列表上每只一枚。关系图底部有 8 个筛选 |
| cv | 详情 | 可空 |
| position | 基础信息 | 推荐站位。样本为前排 |
| role_summary | 基础信息 | 一句定位，不是职业枚举 |
| gender | 档案 | 男 / 女，可空 |
| birthday | 档案 | 如 7月7日 |
| birthplace | 档案 | 可写「未知」 |
| height | 档案 | 文本，保留单位 |
| weight | 档案 | 文本，保留单位 |
| story | 档案 | 人物资料，可展开。文档里不存原文 |
| power | 详情底部 | 图鉴展示用战斗力，不是养成结算 |
| awaken_state | 图鉴加成、排序 | 样本为已满。排序可按觉醒 |
| dex_bonus_attr | 图鉴加成 | 这一只加成落在哪一项，样本为魔防 |
| dex_bonus_pct | 图鉴加成 | 百分比 |
| dex_bonus_flat | 图鉴加成 | 固定值 |
| obtain | 「获得」 | 入口在，正文未打开 |

三枚菱形标记先不要填进属性或职业。

账号级的图鉴总加成（生命、攻击、物防、魔防，各有百分比和固定值）不属于精灵行，单独记在账号或图鉴进度上。当前进度 409/415 也记在那里。

## 技能

图鉴和精灵背包打开的是同一条技能。每个形态单独挂自己的技能，因为进化后技能组成会变。等级文案在 `t_btl_skill`，有的技能只有 1 级，有的到 5 级。

`backend/data/skills.csv` 一行是某个形态的某一级：槽位、等级、名字、类型、物攻或魔攻、目标和描述。

神迹悖理·圣祭圣龙这一形态是：被动不灭信仰、普攻圣光垂佑（物攻）、超杀神迹之价（物攻）、元技恩泽遍临（源迹技）。页面上先展示 1 级描述，和游戏里点开技能看到的一致。

## 羁绊

图鉴里有两套，分开存。

上阵羁绊：详情里有这个区块。样本是空的。

深藏身名：两只精灵加一条效果。样本是「受到的攻击伤害降低 10%」。

精灵关系是第三套，画在另一张图上：

| 字段 | 说明 |
| --- | --- |
| group | 关系组名，如火之试炼、红炎、英雄之旅 |
| progress | 如 10/10、5/5 |
| members | 组内精灵，含未点亮的问号 |
| link | 两只精灵之间的一条连线 |

## 形态和进化

游戏里一只精灵可以有多个形态，每个形态是单独的种族 ID，技能和养成都不共用。时代就是进化阶段：神曜来自神格突破，源起来自源起进化，神启来自神启进化。`backend/data/evolutions.csv` 记录从哪个形态进化到哪个形态。

同一皮肤名会跟着形态各有一行，用皮肤组编号串起来。皮肤图鉴左侧的品级是神话、圣品、性转、绝品、臻品、精品、良品。皮肤海报是另一页，这次没有单独拆。

## 职业

`t_pet_details.role` 和每张皮肤上的 `job` 都是逗号分隔的多个职业。精灵上的职业是这些值的并集。筛选「平衡」时，只要其中一个职业是平衡就会出现。

单独的表是 `backend/data/spirit_jobs.csv`：种族 ID、精灵名、一个职业。

## 皮肤

`t_pet_skin` 里多行可以挂同一个种族 ID。本体是皮肤 ID 等于种族 ID 的那一行，其余是皮肤。每张皮肤有自己的名字、属性和职业。

单独的表是 `backend/data/skins.csv`。页面点开精灵后，右侧列出全部皮肤。

## 和最初分类的差别

图鉴已经证实的：

- 稀有度就是传说、超能、幻兽、初代，另加收集状态「未探明」。
- 站位在详情里，叫推荐站位。
- 物攻写在技能格上。
- 档案六项和官网宠物资料是同一类：性别、生日、出生地、身高、体重，再加故事。
- 属性在卡片和关系图上筛选，关系图是 8 个。

图鉴里还没有写成枚举、所以先不要填死的：

- 时代（源起、神曜、神启）。
- 职业那一长串。详情没有职业一栏，只有一句定位。
- 技能效果标签。
- 源、空、创三个图标的正式名字。

官网详情里的雷达、前排/后排格子、星神四槽，这个图鉴界面没有。不要把官网字段和图鉴字段合成一列，来源不同就分列。
