## 统一原理（所有实现共同点）

液态玻璃 = 折射 + 色散 + 高光，三者都基于同一个「位移向量场」：

1. **形状用 SDF 描述**（圆角矩形 / 圆 / 超椭圆）。
2. **折射位移 = 高度剖面函数 × SDF 梯度（法线）**。
3. **位移场编码进贴图**（R=dx, G=dy），运行时采样贴图做 UV 偏移。
4. **色散 = 不同通道/颜色沿位移场做不同强度的偏移**。
5. **高光 = 法线 · 光方向 的幂次**（物理方向性高光）。

### 核心公式（各实现一致）

```
折射剖面（凸圆）:  circleMap(x) = 1 - sqrt(1 - x²)
折射位移:          d = circleMap(1 - sd/refractionHeight) * refractionAmount
折射后坐标:        refractedCoord = coord + d * normalize(gradSDF)
高光强度:          intensity = pow(abs(dot(normal, lightDir)), falloff)
```

## 各实现的差异与取舍

### SVG 路径（liquid-glass-main / kube.io）

- `feDisplacementMap` + `feImage`（位移图）+ `backdrop-filter`。
- 位移图在 CPU 生成（127 次射线模拟或逐像素计算）。
- 局限：SVG 滤镜当 backdrop-filter 仅 Chromium 支持；动态尺寸需重建位移图。

### GPU 路径（liquid-glass-studio / Cocos / AndroidLiquidGlass-kmp）

- WebGL2 四 pass（背景 → 竖模糊 → 横模糊 → 合成）；或单 DrawCall 着色器。
- Cocos 单 DrawCall 内最多 4 次采样完成折射+色散+高光。
- Android 用 RuntimeShader(AGSL)，SDF + 梯度直接在 GPU 算，无位移图贴图。
- 色散：Android 用 7 采样（红橙黄绿青蓝紫），比 3 通道更真实。

## 对本项目的启示

### 已对齐（Web demo 已实现）

- 超椭圆 SDF 裁切、位移透镜、球面晶体、长虹锯齿、三通道色散、冲击帧、液态金属/Y2K 材质。
- **SDF 梯度（法线）折射**：`lens()` 已从向心 `(ux,uy)` 改为沿 `gradRoundedRectSDF` 方向偏移。
- **circleMap 凸圆剖面**：`lens()` 折射位移改用 `circleMap(x)=1-√(1-x²)`，边缘位移最大、向中心递减，物理与凸透镜一致。

### 待对齐（正式实施时改进）

1. **色散升级 7 采样**：留到 WebGL2 方案（SVG filter 里 7 次 feDisplacementMap 过重）。
2. **方向性高光**：当前 CSS 渐变近似，WebGL2 时对齐 `dot(grad, lightDir)^falloff`。
3. **组合式 effect DSL**：借鉴 `vibrancy() + blur() + lens()` 链式声明，把效果做成可组合而非硬编码。

### 技术判断的印证

AndroidLiquidGlass-kmp 用 GPU RuntimeShader 而非 CPU 合成，再次印证：
- **GPU 着色器是正解**，SVG 是降级方案。
- 位移图可预计算（SVG 路径）或直接 GPU 算（RuntimeShader 路径），都不该在前端运行时逐像素重算。

## 落地顺序

1. 先在 `packages/ui` 里把「SDF 梯度折射 + circleMap 剖面」对齐（Web 端可先在 SVG 位移图里实现）。
2. 色散 7 采样、方向性高光留到 WebGL2 后端（参考 liquid-glass-studio 的多 pass 结构）。
3. 效果 DSL 抽象成 `effect(vibrancy) + effect(blur) + effect(lens)` 链式组合。
