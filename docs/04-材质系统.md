# 材质系统 · 冷色神迹工艺

这份文档把十个词——Y2K、液态金属、高斯模糊、长虹玻璃、哑光反射、风格化硬表面、镜头畸变模拟色散、低饱和冷色主视觉、高饱和动效冲击帧、液态玻璃——落实成奥奇网页端可执行的材质系统。它是 `docs/03-液态玻璃设计方案.md` 的上位文档：03 讲玻璃怎么做，04 讲整套画面怎么做、每个词放在哪。

## 一句话原则

静止画面保持低饱和冷色、哑光、清楚；高饱和和色散只出现在按下的 100 到 160 毫秒。一屏只允许一个液态金属主按钮、一个 Y2K 装饰、一个神迹晶体。

## 十个词逐一落地

### 1. 低饱和冷色主视觉

这是全系统的底色，不是某个组件。

- 是什么：蓝灰、银、薄荷影，饱和度压低后的冷色系。整个静止画面都落在这个基调上。
- 用在哪：场景层、背景、大面板、正文环境、未选中卡片。
- 不用在哪：主按钮、冲击帧、传说/神话徽章。
- 技术实现：OKLCH 色相压在 `215°–260°`，彩度 C 压到 `0.03–0.10`，明度 L 走 `0.14–0.92`。用 `color-scheme: dark` + 冷色渐变底，不加全局滤镜。
- 关键规则：八个属性（水、火、草、光、暗、源、空、创）在静止时都压成低饱和冷灰调，只有在交互或冲击帧时才回到本色高饱和。属性色不喧宾夺主。

### 2. 高斯模糊

高斯模糊承担两个职责：场景景深，以及玻璃背后的背景采样。

- 场景景深：焦点清楚，前景和画面边缘虚化。只打在场景层，不打在文字和按钮上。
- 玻璃背景：玻璃面板用 `backdrop-filter` 采样背后的颜色，模糊后透出场景冷暖。
- 技术实现：场景层给不同深度的元素不同 `blur()`；玻璃层用 `backdrop-filter: blur()`。弹窗打开时背景模糊渐进加深。
- 参数：场景景深 1–6px；玻璃面板 24–36px；弹窗背景 8–16px。
- 边界：文字和按钮永远不模糊；玻璃层内容浮在模糊之上。

### 3. 液态玻璃

这是最核心的一种材料，分三档，不能混用。详见 `docs/03-液态玻璃设计方案.md`。

- 静态玻璃：大面板、设置项、信息栏。`backdrop-filter` + 边光 + 长虹细纹 + 超椭圆裁切。
- 焦点透镜：选中卡片、关键浮层。用 SVG `feDisplacementMap` 做真实背景位移，边缘轻微鼓起。
- 神迹晶体：源核、觉醒冲击瞬间。做 rim、bloom、折射，是页面唯一的视觉主角。

三个案例的技术结论（`liquid-glass-main` / `liquid-glass-react-main` / `liquid-glass-studio-main`）：

- 高级感来自「形状驱动的折射」，不是更大的 blur。
- `liquid-glass-main` 用 `roundedRectSDF` + `feDisplacementMap`，矩形玻璃靠距离场羽化边缘。
- `liquid-glass-react-main` 是同一思路的 React 封装，Tab 高亮块用 60×38 的小透镜做果冻弹性。
- `liquid-glass-studio-main` 是最完整的参照：WebGL2 四 pass（背景 → 竖向模糊 → 横向模糊 → 合成），把折射、色散、菲涅尔、眩光、模糊、阴影拆成独立步骤。它的默认参数是可复用的基准：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| refThickness | 20 | 折射厚度，决定边缘折射带多宽 |
| refDistance | 0.05 | 折射采样偏移距离 |
| refFactor | 1.4 | 折射率 |
| refDispersion | 7 | 色散强度 |
| refFresnelRange | 30 | 菲涅尔边缘范围 |
| refFresnelFactor | 20 | 菲涅尔强度 |
| glareRange / glareFactor | 30 / 90 | 眩光范围与强度 |
| glareAngle | -45° | 眩光方向 |
| blurRadius | 1–200 | 高斯模糊半径 |
| shadowExpand / shadowFactor | 25 / 15 | 阴影扩散与强度 |
| shapeRadius | 80 | 圆角半径（相对形状） |
| shapeRoundness | 5 | 超椭圆指数，约等于连续圆角平滑度 |

网页端不必照搬 WebGL 全链路，重点是**借鉴它的分步思想**：折射、色散、菲涅尔、眩光各自独立可控，而不是压在一层里。

### 4. 长虹玻璃

竖向细棱，把背景按竖条折射，像带棱的玻璃。

- 用在哪：侧栏导轨、图鉴书页分页、卡片一侧的细棱条。
- 不用在哪：正文底下、大面积说明板。
- 技术实现：Chromium 用 SVG filter 的横向锯齿位移图；其它浏览器退回 `repeating-linear-gradient` 竖棱 + 轻模糊 + 高光边。
- 边界：棱条只占窄条，不铺满整块面板。

### 5. 哑光反射

次级表面的柔和广域反光，不是锐利镜面。

- 用在哪：未选中卡片、开关轨道、导航、分段选择底。
- 不用在哪：主按钮（那是液态金属的镜面高光）。
- 技术实现：极轻的噪点颗粒纹理 + 一个宽而柔的高光渐变，避免锐利高光点。颗粒用 `feTurbulence` 或低透明度 SVG noise 叠加。

### 6. 风格化硬表面

面板缝、倒角、刻槽、内槽、机械刻度，让控件像精加工零件。

- 用在哪：面板边缘、分段选择、预览卡倒角、属性条刻度、技能格（做成「硬表面插槽」）。
- 技术实现：内阴影做倒角/雕刻感；刻槽用「暗线 + 亮线」两条紧贴；进度条加刻度；数值面板做成仪表盘质感。
- 关键规则：角仍是连续圆角，硬表面的「硬」来自倒角和刻槽，不来自直角。

### 7. 镜头畸变模拟色散

- 静止：画面最外缘极轻的色边 + 径向渐晕。
- 冲击：冲击帧上 1px 的红青分离。
- 技术实现：静止用极轻的径向渐晕 + 边缘 `text-shadow`/描边色散；冲击帧用 WAAPI 关键帧把 R/G/B 通道短暂偏移 1px。
- 边界：色散只出现在冲击帧或画面最外缘，正文永远不色散。用户开了减少动效时，色散直接到位不分离。

### 8. 液态金属

一屏唯一的主按钮，加一处主角装饰。

- 特点：高光是被拉长的镜面，不是一圈发光。模拟环境映射：上亮带、暗地平线、下冷暖反光。
- 技术实现：多段渐变模拟环境图 + 一条动画镜面扫光 + 可选 `feTurbulence` 让铬面流动。
- 用在哪：大厅「开始游戏」、设置页「恢复默认」、养成页「升级」。
- 不用在哪：大段文字底、次级按钮、图鉴列表里的每一张卡。

### 9. Y2K

铬面、透亮塑料、一小块贴纸高光、全息。

- 用在哪：传说/神话徽章、源核铭牌、「NEW」贴纸这一处主角装饰。
- 不用在哪：整页贴图、复古拼贴、大面积铺。
- 技术实现：conic 渐变模拟铬面 + 全息虹彩 + 星点 glint。液态金属是「汞的流动」，Y2K 是「复古未来铬塑料」，两者分开用。

### 10. 高饱和动效冲击帧

- 触发：按下、页切换、领奖、觉醒、星级提升、神话皮肤抽出、未探明解锁。
- 时长：100–160ms，结束立刻回到冷色。
- 技术实现：WAAPI 关键帧——轻微压缩 → 带色散的过冲 → 弹簧缓动回稳；叠加一层 flash 白/彩闪。饱和度在冲击瞬间拉高，结束后回落。
- 边界：冲击帧结束后画面必须回到低饱和冷色，不能残留。

## 材质阶梯：让材质表达稀有度与品级

奥奇里有两套等级，可以用材质阶梯来编码，这是「这套设计为什么属于奥奇」的关键。

### 稀有度（图鉴）

| 稀有度 | 材质 |
| --- | --- |
| 初代 | 哑光，无高光 |
| 幻兽 | 轻玻璃，边缘亮线 |
| 超能 | 长虹玻璃边 |
| 传说 | 液态金属细边 + Y2K 铬徽章 |
| 未探明 | 磨砂玻璃，轮廓藏在模糊里 |

「未探明」用磨砂玻璃是核心创意：材料直接表达游戏状态——没点亮的精灵轮廓被 blur 藏起来，解锁时磨砂化开、饱和度冲击、色散分离，再回到冷色实卡。

### 皮肤品级（皮肤图鉴）

| 品级 | 材质 |
| --- | --- |
| 良品 | 哑光 |
| 精品 | 哑光 + 边缘亮线 |
| 臻品 | 玻璃 |
| 绝品 | 长虹玻璃 |
| 性转 | 特殊虹彩 |
| 圣品 | 液态金属细边 |
| 神话 | Y2K 铬 + 全息贴纸 + 晶体 |

列表里多张传说卡并排时，只有聚焦/选中的那张徽章才转成铬，其余保持扁平的刻槽，保住「一屏一个液态金属/Y2K」的克制。

## Z 轴层级模型

从后到前：

1. L0 场景：低饱和冷色、景深、边缘轻畸变。
2. L1 静态玻璃：面板、任务板，`backdrop-filter` + tint + 边光 + 颗粒。
3. L2 哑光控件：未选中卡、开关、导航，硬表面倒角。
4. L3 焦点透镜 + 液态金属主按钮：唯一主行动，浮在最前。
5. L4 装饰 + 冲击覆盖：Y2K 徽章、神迹晶体、色散 flash。

## 玻璃参数面板与预设

参照 `liquid-glass-studio-main` 的参数面板，网页端在 `model.html` 右侧做了「玻璃参数」面板，可实时调参并内置预设。参数分两组：

- 折射组（作用于 `feDisplacementMap` 位移图）：折射强度、折射厚度、色散、边缘鼓起。
- 光照组（作用于 CSS 变量）：菲涅尔、眩光、背景模糊、阴影。

四个内置预设（「好看的设置」已调好，直接可用）：

| 预设 | 折射强度 | 折射厚度 | 色散 | 鼓起 | 菲涅尔 | 眩光 | 模糊 | 阴影 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 冷色神迹（默认） | 1.6 | 0.85 | 0 | 0 | 0.55 | 0.42 | 30px | 0.34 |
| 深空琉璃 | 2.4 | 0.90 | 12 | 6 | 0.72 | 0.50 | 36px | 0.42 |
| 晨雾冰晶 | 1.2 | 0.75 | 3 | 0 | 0.32 | 0.62 | 48px | 0.20 |
| 高对比铬晶 | 1.8 | 0.92 | 18 | 10 | 0.92 | 0.80 | 22px | 0.50 |

实现要点：

- `aoqi-material.js` 的 `lens()` 支持 `update(next)` 实时重建位移图与滤镜，重建时销毁旧 filter，避免累积。
- 色散用三通道 `feDisplacementMap`（R 弱一点、B 强一点，对应 N_R<N_G<N_B）。
- 光照参数通过 `.aq-glass` 的 CSS 变量 `--aq-fresnel` / `--aq-glare` / `--aq-blur` / `--aq-shadow` 控制，`lens()` 实例暴露在 `element.__aqLens`，控制面板直接调用 `update()`。
- 手动拖动滑块会清除预设高亮；点预设按钮恢复高亮并整体切换。

## 边界规则（克制）

- 一屏一个液态金属主按钮、一个 Y2K 装饰、一个神迹晶体。
- 强折射不进文字区；文字永远在最上层。
- 可交互元素永远不模糊。
- 高饱和和色散只在冲击帧或画面最外缘；用户开启减少动效时，冲击帧改为颜色直接到位，不做色散和位移。
- 大面积说明板保持安静，不做强效果。

## 为什么这套属于奥奇

- 源核、星神、灵纹直接翻译成晶体和刻槽硬表面。
- 未探明翻译成磨砂玻璃。
- 稀有度和皮肤品级翻译成材质阶梯。
- 八属性在静止时低饱和、交互时高饱和，材料表达状态和价值。
- 时代可映射为场景色温的轻微变化。

这是奥奇的冷色神迹工艺，不是任何一款自走棋或卡牌游戏。

## 落地顺序

1. `prototype/aoqi-material.css`：token + 材质类。
2. `prototype/aoqi-material.js`：超椭圆 clip、透镜位移、长虹、颗粒、色散 split + `impact()`。
3. 升级 `prototype/model.html` 把十个词呈现出来。
4. 后续页面（图鉴列表、精灵详情、皮肤、关系图、养成、设置）复用同一套类。
