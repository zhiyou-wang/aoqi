# 图鉴界面

主界面底部一排功能按钮，从左到右是：小诺助手、奥核、公武、布阵、图鉴、背包、社交、精灵。图鉴是一本打开的书，点进去就是图鉴。

付费、抽卡、年费、一键强化没有点。

## 列表

顶栏是「图鉴总加成」，四项：生命、攻击、物防、魔防。每一项同时有百分比和固定值。这是账号收集进度的汇总，不是单只精灵的面板。

书的左页上方是收集进度，当前为 409/415。左缘竖排分页：

- 全部
- 传说
- 超能
- 幻兽
- 初代
- 未探明

前四档和稀有度一致。未探明是册子里还有、账号还没点亮的条目。409 与 415 的差就落在这里。

右页有搜索框，占位文案是「点击输入要搜索的精灵名字」。旁边是筛选按钮，以及排序。排序只有两项：默认、觉醒。筛选面板这次没有稳定打开，里面的条件还不能当字段清单用。

每页像摊开的书，左右各一页，页码写成「第1页」「第2页」。一张卡片只显示立绘、竖排名字、底部一枚属性图标。名字带间隔号，例如「神迹悖理·圣祭圣龙」。

左上角另有「皮肤图鉴」。右下角有「精灵关系」和「一键强化」。一键强化是操作按钮，不进资料表。

## 详情

点卡片进入详情。样本是「神迹悖理·圣祭圣龙」。

顶上仍是图鉴总加成。左侧是立绘、稀有度（传说）、名字、CV（王宇航）、战斗力，以及「获得」。获得没有点开，它是获取途径的入口。立绘左侧还有三枚菱形标记，点按没有弹出名称，这三枚先不要猜成属性或职业。

右侧三个页签。

### 基础信息

攻略：

- 推荐站位。这一只是「前排」。
- 一句定位，例如分摊伤害、护盾、回血。

技能一排图标，图标上有类型，图标下有技能名。这一只是四格：

| 类型 | 名称 |
| --- | --- |
| 被动 | 不灭信仰 |
| 物攻 | 圣光垂佑 |
| 超杀 | 神迹之价 |
| 唤起技 | 恩泽遍施 |

物攻写在技能上，不写在精灵的站位上。唤起技是图鉴里单独的一格，和职业里的「唤灵」不是同一个字段。

上阵羁绊：这一只的区域是空的。

深藏身名：两只关联精灵，中间有连线，下面有效果说明（受到的攻击伤害降低 10%）。这是另一套羁绊，不要和上阵羁绊合成一列。

### 档案介绍

基础档案：

- 名字
- 性别
- 生日
- 身高
- 出生地（这一只是「未知」）
- 体重

下面是人物资料，可继续展开。再下面是精灵皮肤，未获得的皮肤会标出来。

### 图鉴加成

按属性查看这只精灵贡献的图鉴加成。样本停在魔防：觉醒已满，同时有百分比和固定值两条。顶上的「图鉴总加成」是全册合计，这里是单只贡献。排序里的「觉醒」和这一页是同一套进度。

## 精灵关系

从列表右下角进入，是一张连线图，不是第二本图鉴。

节点是精灵，例如火力马、力星王者·龙炎、烈阳·龙君焰、暴力少女·茜茜、石姬新娘·镭拉、问号（未点亮）。连线表示进化或关联。

右侧是关系组，带收集进度：

- 火之试炼 10/10
- 红炎 5/5
- 英雄之旅 5/5

底部一排 8 个属性筛选。能辨认的是火、水、草、光、暗。另外三枚是几何图形和龙形，和「源、空、创」数量一致，但没有逐个点开，名字先空着。右下角有「查看总览」。
