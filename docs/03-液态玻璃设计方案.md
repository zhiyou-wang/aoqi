# 液态玻璃设计方案

这份方案用于网页端 UI。目标不是把外部示例原样贴进项目，而是把它背后的高级感来源拆出来，沉淀成奥奇自己的「冷色神迹工艺」玻璃体系。

## 当前差距

我们现在的模型主要靠 `backdrop-filter`、半透明填色、边缘高光和超椭圆裁切。它能做到“像玻璃的面板”，但还不像“液态玻璃”。

外部示例高级感更强，核心原因有五个：

- 它不是只模糊背景，而是用 SVG `feDisplacementMap` 做背景位移。玻璃内部看到的背景会被折射，边缘附近尤其明显。
- 它有形状感。矩形玻璃使用 `roundedRectSDF` 算距离场，钻石玻璃使用 3D 面、法线、折射率和投影外轮廓。也就是说，视觉效果跟具体形状绑定，不是一层通用灰蒙蒙滤镜。
- 它把主体折射、边缘隆起、rim 边光、bloom 泛光分开做。我们之前把这些都压在一层背景和阴影里，所以显得平。
- 它有物理参数。比如折射率、边缘鼓起、位移上限、内部反弹、阻尼、弹性边界。这些参数让动起来的时候有材料重量。
- 它只把高级效果给一个焦点对象。页面其他元素安静，焦点玻璃才显得贵。

结论：液态玻璃的高级感来自“形状驱动的折射”，不是更大的 blur，也不是更亮的边框。

## 奥奇自己的玻璃分层

网页端分三档，不同档位不能混用。

### 1. 静态玻璃

用于大面板、列表、右侧信息栏、设置项底板。

特点：

- 低饱和冷色染色。
- 背景采样模糊。
- 上沿亮边，下沿暗边。
- 轻微长虹竖纹。
- 连续圆角，但不做强折射。

实现：

- CSS `backdrop-filter`。
- 半透明渐变。
- 伪元素做边光和竖纹。
- JS 生成超椭圆 `clip-path`，避免普通圆角。

这层负责承载信息，文字必须清楚，不追求炫。

### 2. 焦点透镜

用于一屏里最重要的一两个玻璃件，例如当前选中的精灵卡、图鉴入口浮层、设置页预览卡。

特点：

- 有真实背景位移。
- 边缘有轻微鼓起，像玻璃厚度。
- 鼠标靠近时折射中心轻微偏移。
- 不大面积使用，否则页面会脏。

实现：

- 用 SVG `filter` 加 `feImage` 和 `feDisplacementMap`。
- 用 canvas 按形状生成位移图。
- 矩形透镜使用超椭圆距离场。
- 折射强度控制在低范围，避免文字变形。

这层是我们和普通玻璃 UI 拉开差距的关键。

### 3. 神迹晶体

用于唯一视觉焦点，例如大厅中央源核、抽卡/觉醒成功瞬间、图鉴主视觉装饰。

特点：

- 可以是钻石、棱镜、源核、灵纹晶体。
- 有面片、法线、rim light、bloom。
- 可在拖动或页面切换时有惯性。
- 不承载正文，只作为视觉主角或动效冲击帧。

实现：

- 借鉴 `liquid-diamond.js` 的结构：3D 点、面、法线、投影 hull、折射追踪。
- 奥奇里不直接做钻石，改成源核晶体、灵纹棱镜或星神碎片。
- 高饱和色只在 100 到 160 毫秒冲击帧出现，静止状态保持冷色。

## 参数基准

静态玻璃：

- 背景模糊：24 到 36。
- 饱和度：1.25 到 1.55。
- 明度：1.04 到 1.1。
- 面板不透明度：0.08 到 0.18。
- 边缘高光：0.35 到 0.6。

焦点透镜：

- 位移强度：4 到 14 像素。
- 边缘隆起范围：14 到 24 像素。
- 边缘隆起强度：0.02 到 0.05。
- 鼠标响应延迟：80 到 140 毫秒。
- 文本区域不参与强折射。

神迹晶体：

- 折射率：1.12 到 1.22。
- 内部反弹最多 4 到 8 次。
- bloom 模糊：24 到 36。
- rim 透明度：0.35 到 0.55。
- 拖拽阻尼：0.9 到 0.96。

这些值先作为默认，不在每个组件里临时拍脑袋。

## 组件规范

玻璃不是一种装饰，而是一种材料。使用时按下面规则：

- 大面板用静态玻璃，不做强变形。
- 当前选中卡片可升级为焦点透镜。
- 主按钮仍然用液态金属，不用玻璃替代。
- 右侧设置项、分段选择、开关只做轻玻璃。
- 页面只允许一个神迹晶体。
- 文字层永远放在玻璃效果上方，不能被折射影响。
- 背后必须有场景、色块或纹理，否则玻璃没有内容可折射。

## 技术落地

第一步，抽一个 `AoqiLiquidGlass` 核心模块。

模块职责：

- 生成唯一 SVG filter。
- 生成 displacement canvas。
- 根据元素尺寸生成超椭圆 mask。
- 支持三档效果：`static`、`lens`、`crystal`。
- 支持 resize 后重算。
- 支持 reduced motion。

第二步，把 `model.html` 里的临时圆角 JS 替换掉。

当前 `model.html` 的超椭圆裁切只是过渡实现。下一版应该统一由 `AoqiLiquidGlass` 接管：

- `.glass` 默认走 `static`。
- `.spirit-card.active` 走 `lens`。
- `.scene-core` 或主视觉源核走 `crystal`。

第三步，建立降级策略。

低性能或不支持 SVG filter 时：

- 保留超椭圆裁切。
- 保留背景模糊和边缘高光。
- 关闭 displacement。
- 关闭鼠标追踪和惯性。

这样页面不会坏，只是少一层高级折射。

## 与外部示例的边界

示例是 MIT，可以学习和改写。但本项目不直接复刻它的外观：

- 不用原示例的固定悬浮玻璃块。
- 不做同款钻石造型。
- 不沿用演示里的拖拽玩具交互作为产品功能。
- 只吸收 displacement、edge bulge、rim、bloom、物理参数这套方法。

奥奇自己的形状语言是源核、灵纹、星神碎片和图鉴卡，不是通用玻璃挂件。
